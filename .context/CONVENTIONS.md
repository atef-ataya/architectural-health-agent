# Conventions

## TypeScript
- Strict mode always on
- Explicit return types on all public methods
- Interfaces for all data shapes
- No any — use unknown and narrow

## Console Output
All emoji prefixes are fixed — do not change them:
- 🔵 Processing / agent steps
- 🧠 Memory operations
- 💾 Store operations
- 🔍 Search operations
- ⚙️ Skill execution
- 📝 Response generated
- 📊 Evaluation score
- 🔄 Retry triggered
- ✅ Success
- ❌ Error
- 📚 Semantic cache

## File Structure
One class per file. Named exports only. No default exports.
